目标：将当前“通用报告 + 含逐事件解释的 selection 报告”拆为统计筛选、事件集合、单事件解释三个层级，明确每层的数据范围，减少重复内容，并支持后续追加。

## 1. 层级与数据范围

| 层级 | 主要问题 | 数据范围 | 推荐入口 |
|---|---|---|---|
| 一级：统计筛选报告 | 哪些已生成事件满足本次 FDR/p 值标准，总体通讯结构如何？ | 概览统计全部已生成事件；主列表和通讯图使用满足标准的事件 | `analysis.report.html` |
| 二级：所选事件报告 | 用户关心的一组事件有什么共同点、差异及样本表现？ | selection 的全部事件 | `analysis.selected.report.html` |
| 三级：单事件报告 | 这个具体事件的评分如何形成，哪些输入和先验支持它？ | 一个发送细胞—代谢物—受体—接收细胞事件，及其全部已有样本记录 | `analysis.reports/events/event_<id>.html` |

一级默认生成；二级和三级是独立、可选的报告，不是必须依次经过的流程。沿用现有参数名：`selection` 指定二级事件集合，`events` 指定三级单事件报告对象，取消当前二者互斥的限制。

| `save(report=True)` 的参数 | 生成的报告 |
|---|---|
| 未指定 `selection` 和 `events` | 一级 |
| 仅指定 `selection` | 一级 + 二级 |
| 仅指定非空 `events` | 一级 + 三级，每个明确指定的事件一份 |
| 同时指定 `selection` 和非空 `events` | 一级 + 二级 + 三级 |

selection 只有一个事件，或筛选条件已经给出完整四项标识，也不会自动触发三级。三级事件不必属于 selection，也不必通过一级统计门槛；页面如实标明其达标状态。不指定 selection 就不生成二级，也不生成所选事件 CSV。

`select_events()` 默认从一级达标事件中筛选。保留显式 `source="all"`：二级可以包含未达一级标准或无法判定的事件，必须展示状态；不把它们重新判定为阳性。三级直接使用所指定事件的原计算结果，不先通过 selection 筛选。

报告分层、筛选、排序和追加均不重新计算评分、置换 p 值或 BH 校正值。BH 校正沿用原计算的检验范围，不在 selection 内再次校正。

## 2. 一级：统计筛选报告

固定四部分，保持当前主报告定位。

### 2.1 分析概览

- 数据名称/结果标识、pooled 或 sample_aware、细胞/基因/样本/细胞类型数量；只有已有来源记录时才显示相应数量，不猜测缺失信息。
- 全部已生成事件数、达标事件数、未达标事件数、无法判定数。
- 本次统计标准明确写为：按受体类型 BH 校正 p 值、全局 BH 校正 p 值，或原始置换 p 值；展示阈值及是否附加 QC/评分门槛。
- 涉及的发送/接收细胞类型、代谢物、受体数量。

默认仍为 `fdr_sensor_type <= 0.05`，一次使用一种主统计量。FDR 字段名称保持兼容，页面解释为 BH 校正后的 p 值。原始 p 值明确标为未经多重检验校正。

### 2.2 通讯概览

- 细胞对事件数热图：默认展开。
- 通讯网络图：默认折叠。
- 图形均使用本次达标事件，明确计数、缺失评分及实际绘图范围。
- 不放代谢物—受体点图，不放逐事件评分组成或表达图。
- 只有一个细胞对时用紧凑文字摘要替代计数热图/网络图；零事件时解释原因，不绘制占位图。

### 2.3 达标事件列表与导出

- 包含全部达标事件，支持搜索、排序、分页；浏览器操作只调整表格视图。
- 默认提供达标事件 CSV；显式 `include_all_events=True` 时另提供全部事件 CSV 下载，保留现有 `all_events.csv`、`positive_events.csv` 文件名。
- 提供报告导航入口；一级不再维护逐事件解释索引。

### 2.4 数据与方法

- 折叠展示完整计算参数、先验版本/来源、输入归档信息、全局覆盖度、统计解释。
- 全局方法和覆盖度集中放在一级，二、三级仅保留理解当前结果所必需的信息与返回链接。
- “阳性/达标”只表示满足本次筛选标准，不代表实验确认。

## 3. 二级：所选事件报告

固定四部分，重点是集合比较；从现有二级移出全部逐事件解释、小提琴图和反应/基因明细。

### 3.1 选择概览

- 简明描述来源（一级阳性或全部结果）及发送细胞、接收细胞、细胞对、代谢物、受体等条件。
- 所选事件总数及达标/未达标/无法判定数量，涉及的细胞对、代谢物和受体数量。
- 保留一级统计口径的简短说明；单独列出 selection 的附加条件。
- 不重复一级的全局覆盖表和完整参数表。

### 3.2 集合比较

| 图形 | 用途 | 默认安排 |
|---|---|---|
| 代谢物—受体 × 有向细胞对点图 | 比较一组事件的组成和评分 | 多事件时优先展开 |
| 细胞对事件数热图 | 比较事件分布 | 多个细胞对时提供，默认折叠 |
| 通讯网络图 | 观察所选事件连接关系 | 多个细胞对时提供，默认折叠 |
| 样本 × 事件评分热图（新增） | 比较同组事件在各样本中的已有评分、零值及缺失 | 仅 sample_aware 多事件时提供，默认折叠 |

- 样本热图直接使用已有样本事件评分，统一使用原评分尺度，NA 与零分分开标识；QC 单独标示，不重新过滤样本，也不生成新的显著性结论。
- 每张图写明总范围、已绘范围和展示上限。热图保留全部样本行，事件列按展示上限控制；完整事件仍在表格和 CSV 中。
- 继续使用 `plot_top_n` 控制集合比较图的特征数量：点图单位为代谢物—受体组合，新增样本热图单位为事件。各图标明单位；计数热图和网络仍使用全部可绘 selection 事件。
- 同一个细胞对存在多个事件时，保留点图及适用的样本热图，不生成 1×1 计数热图或单边网络图。
- selection 只有一个事件时，二级仍保留选择来源、简洁事件摘要和事件列表，省去集合比较图；仅在对应三级已另行生成时显示链接，不自动生成三级或改成另一类报告。
- selection 为空时保留条件、表头和空结果说明，不生成集合图形；不影响独立指定的三级报告。

### 3.3 完整事件列表

- 包含全部 selection 事件，提供所选 CSV 下载。
- 展示稳定的报告事件编号、四项事件标识、通讯评分、p 值/BH 值、达标状态；sample_aware 保留已有的样本数/出现比例等字段。
- 每行提供“查看单事件报告”或“尚未生成”状态；未生成时提供可复制的追加代码。
- 所有行都保留，不因是否生成单事件报告而截断。CSV 沿用现有科学字段及 `positive_status`，报告事件编号先放在 HTML/交付元信息中，不强制改变 CSV 表头。
- 不再在列表下重复插入多个事件的评分面板，也不另设重复的解释索引。

### 3.4 筛选与导出说明

- 默认折叠：完整筛选条件、逐步剩余数量、排序规则和图形展示范围。关联的三级页面只标记是否已另行生成，不设置自动生成范围。
- 支持只填一个条件或任意部分条件；未指定的字段不限制。例如只指定 `hmdb_ids` 和 `sensor_genes`，即在选定来源内查找该组合涉及的所有已有发送—接收细胞对，不要求补齐两端细胞。
- 不同筛选条件取交集，同一条件内取并集；保持现有 `select_events()` 语义。`cell_pairs` 与发送、接收、代谢物、受体条件同时设置时也取交集。
- 多个 `hmdb_ids` 与多个 `sensor_genes` 表示两个集合的交集筛选，匹配结果中所有符合条件的组合，不按列表位置一一配对，也不构造不存在的事件。单个代谢物—受体组合各传一个值即可；本轮不增加新的配对参数。
- 明示图形展示上限不影响 selection 本身或 CSV；三级的生成范围由 `events` 独立决定。

## 4. 三级：单事件报告

一个 HTML 对应一个稳定的四项事件标识，包含五部分。它可以单独打开阅读；导航依赖的关联文件采用相对路径。

- `events` 中每项必须明确提供 `sender`、`hmdb_id`、`sensor_gene`、`receiver`，分别对应发送细胞、代谢物、受体/传感器和接收细胞。代谢物使用 HMDB 标识匹配，名称用于展示。
- 缺少任一项应在写入前报错并指出缺失字段，不将部分标识自动展开为多份三级报告；此类集合筛选应使用 `select_events()`。
- 指定多个完整事件就生成多份独立页面。重复的完整事件标识在写入前报错，避免重复请求或不明确的覆盖。报告事件编号用于文件定位和链接；公开调用仍提供完整标识，列表中的可复制代码包含四项标识。
- `events=None` 或空列表不请求三级报告。仅生成三级时不要求先创建 selection，追加三级时也不更改已有 selection。

### 4.1 事件概览

- 用紧凑通讯路径展示“发送细胞 → 代谢物/HMDB → 受体 → 接收细胞”。
- 通讯评分、原始置换 p 值、BH 校正值及其范围、本次一级标准下的状态。
- 分析模式与样本概况；不能计算、输入缺失或零分的原因单独说明。
- 不画单事件计数热图、单边网络图或单气泡概览。

### 4.2 评分分解

- 发送端：P/C/E 标准化值、基础可用性、外排有效值与调节系数、最终发送端评分，合并为同一组解释。
- 接收端：平均表达、表达比例、标准化参考值、门控条件及门控后评分。
- 参考值、细胞比例调整及当前实际采用的计算关系以简明图文说明；原始值和完整参考上下文放入折叠明细。
- pooled 展示合并分析的组成。sample_aware 提供样本选择器，在明确显示的当前样本下查看组成；所有样本均可访问，取消只能查看前 10 个样本组成图的限制。
- sample_aware 汇总评分单独列出，明确它是样本事件评分的中位数，不把各组成项中位数的乘积当作最终评分。
- 汇总事件统计与当前样本的组成值分别标注；没有计算过的样本级 p 值/BH 值不得补造。旧接口指定样本时，页面明确标注所查看的样本与汇总统计所属范围。

### 4.3 样本表现（仅 sample_aware）

- 全部样本的事件评分图，保留 NA、零分、QC 状态与中位数。
- 展示已有的可计算样本数、正评分样本数/比例、通过细胞数 QC 的样本数。
- 样本图与组成图的样本选择联动，便于从异常/零分样本进入具体组成。
- pooled 省去整节，不伪造逐患者分解；正评分比例不称为显著率或重复验证率。

### 4.4 表达证据与先验覆盖

- 发送端生产相关表达小提琴图、接收端受体表达小提琴图，仅涉及当前事件对应细胞类型和目标。
- 精简列出 P/C/E 与受体的输入覆盖情况、缺失基因和先验缺口；只描述覆盖，不新增“可靠性总分”。
- 缺少单细胞表达输入时保留可用的评分/先验解释，明确哪些表达图未生成；仅使用显式 `adata` 或已保留输入，不隐式加载大型归档。
- 图注说明表达证据不等于实测代谢物浓度或外排通量；sample_aware 小提琴图按细胞类型合并所提供输入的细胞，不冒称逐样本验证。

### 4.5 明细与出处

- 按“样本与评分”“反应与基因”“先验与标准化参考”分组折叠，表格支持分页，不用静默前 100 行预览代替完整事件明细。
- 记录结果标识、事件标识、一级统计标准和报告版本；全局参数链接回一级。
- 默认只生成这一份 HTML，不额外生成每事件 H5、CSV、PNG 或 PDF；完整科学数据仍在同一个结果 H5 中。
- 对显式请求的未生成候选，只能输出明确标为“未生成/诊断”的解释，不能构造评分、统计值或向结果 CSV 增加事件。

## 5. 数量控制与图形安排

- 二级列表与 CSV：始终完整。
- 集合比较图：默认 `plot_top_n=20`，仅控制图形的展示范围；`None` 表示不限。图形不改变 selection。
- 三级不自动生成，不设“默认前 N 个”。只生成 `events` 明确指定的完整事件，不受 `plot_top_n` 或 selection 排序影响，不静默截断显式请求。
- `detail_n` 退出新报告接口的推荐用法；兼容期识别旧调用并给出弃用提示及迁移示例，但不能再据此从 selection 自动生成三级，也不能截断显式 `events`。旧交付记录中的 `detail_n` 不转换为新三级生成请求。
- 报告对象以本次显式请求为准。新布局下，`save()` 不从历史交付记录隐式恢复 selection 或 events；需要复用 selection 时显式传入 `result.get_selection()`。统计口径及图形设置的继承与报告对象的选择分开处理，并记录此兼容性变化。
- 小图不强制放大至整页宽；按适当的原始尺寸居中，大图按容器缩小。图片完整展开，不使用图片内部滚动条。计数图采用整数刻度，退化为单一计数的情形优先使用摘要。

## 6. 文件与导航

建议保留当前文件名，将第三层集中在一个子目录，避免顶层堆积文件。

```text
analysis.cellmesh.h5
analysis.all_events.csv                    # 仅 include_all_events=True
analysis.positive_events.csv
analysis.report.html                       # 一级
analysis.selected_events.csv               # 指定 selection 时
analysis.selected.report.html              # 二级，指定 selection 时
analysis.input.h5ad                         # 可选，默认不输出
analysis.reports/
    index.html                             # 轻量导航，不是第四种分析报告
    events/
        event_<稳定编号>.html               # 三级，仅 events 明确指定的对象
```

- 导航页只列报告入口和已生成状态，不复制分析图表、统计值或完整事件表。
- 设置导航页的目的：一级只需保留固定入口；追加二/三级时更新导航和相应页面，保持一级 HTML 及全局 CSV 原字节不变。相比当前输出增加一个很小的固定导航文件。
- selection 与 events 都未指定时只有一级及导航；仅指定其中一个时只增加相应层级，不生成另一层的占位报告。`report=False` 关闭全部三类 HTML 与导航；达标 CSV 仍输出，全量 CSV 仅由 `include_all_events=True` 开启，显式 selection 增加所选 CSV，events 不增加事件 CSV。
- 三级通过稳定事件编号定位，排序或分页改变不影响文件名；完整标识在页面和交付记录中可查，不能依赖易变化的行号。
- 同一事件页可复用已提取的证据；不为每个事件重新读取完整 H5 或重建全局解释表。共享图在生成时缓存，页面默认自包含，不额外堆积图片文件。
- 当前一个前缀维护一组 selection 的约定保留；多个独立 selection 可用现有独立导出入口和不同名称，不在本轮引入复杂的多组项目管理。

## 7. 调用与追加（已实现）

保留常用入口，`selection` 与独立参数 `events` 分别控制二级和三级；为后续补充单事件页增加 `add_event_reports()`。以下用法已实现；示例标识需替换为实际结果中的标识。

```python
# 二级：只限定代谢物—受体，不限定发送/接收细胞
focus = result.select_events(
    hmdb_ids=["HMDB0001999"],
    sensor_genes=["SLC8A1"],
)

# 三级：另行明确给出完整事件标识
event = {
    "sender": "Epithelial",
    "hmdb_id": "HMDB0001999",
    "sensor_gene": "SLC8A1",
    "receiver": "Myeloid",
}

# 四种独立选择，实际使用时按需执行其中一种
result.save("general/analysis")
result.save("selection_only/analysis", selection=focus)
result.save("event_only/analysis", events=[event], adata=adata)
result.save("both/analysis", selection=focus, events=[event], adata=adata)

# 也可以先交付一级，再按任意顺序追加二级或三级
result.save("append/analysis")
result.add_event_reports([event], adata=adata)  # 仅追加三级，不创建 selection
result.add_selection(focus)                   # 仅追加二级，不自动生成三级
```

- `add_event_reports()` 为新增接口；与 `events` 使用相同的完整标识序列。只补充请求的单事件页、导航及已有二级列表的链接状态，不创建二级，不改变 selection 或一级统计标准。覆盖已生成页面需显式 `replace=True`，仅更新明确请求的对象。
- 未指定 selection 也可显式生成一个事件页；该操作不会暗中创建或改变一组 selection。
- `result.to_html(path)` 仍可独立导出一级；`focus.to_html(path)` 只导出二级。`result.to_html(path, events=[event])` 只导出该三级页面，无需先输出一级或二级。多个 events 时 `path` 作为导航页，各事件页写入旁侧目录；同时指定 selection 时 `path` 为二级并链接独立三级页面，返回值给出每个实际文件路径。
- 现有显式 `events` 入口迁移到三级解释导出，不再触发二级或所选 CSV，不再把多个解释块堆入二级。旧的指定样本能力作为页面初始样本定位保留，不减少可访问的样本；未生成候选诊断能力保留并明确标识。
- 追加和替换保持覆盖保护及失败回滚。只管理本前缀登记的生成文件，不清理用户手工另存文件；替换 selection 仅更新二级及关联链接，不能删除或覆盖独立请求的三级页面。追加三级也不改写所选 CSV。对已有前缀的增量操作使用两个追加入口；`save()` 的对象选择不被解释为清理历史文件的指令。
- 改变一级统计口径时使用新前缀，或同步重建受影响的下级状态；禁止新旧统计标签混用。
- 旧两级交付首次迁移允许重建报告和导航；迁移后追加保持一级字节不变。H5 科学内容和科学 CSV 不随报告迁移改变，交付元信息记录三级布局版本。
