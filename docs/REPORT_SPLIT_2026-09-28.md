# 通用报告与所选报告分离

> 历史记录：当前结构已改为[三级报告](THREE_LEVEL_REPORTS.md)，全量 CSV 仅由 `include_all_events=True` 开启。下文默认文件数及全量 CSV 行为不代表当前版本。该开关修正[尚待统一测试](ALL_EVENTS_CSV_REVISION_2026-09-29.md)。

本轮只修订交付和展示，不修改评分、事件空间、置换或 BH 校正。

## 输出与入口

- `result.save("analysis")`：H5、全量 CSV、阳性 CSV、通用 HTML，共 4 个文件。
- `result.save("analysis", selection=focus)`：再加所选 CSV、独立所选 HTML，共 6 个文件。
- `result.add_selection(focus)`：追加所选结果；通用 HTML/CSV 保持原字节内容，H5 仅更新交付元信息。替换已有选择须 `replace=True`。
- `report=False`：不生成两类 HTML，追加时继承该设置；数据交付保持可用。
- `result.to_html(path)`：独立通用 HTML 和全量/阳性 CSV；`focus.to_html(path)`：独立所选 HTML 和所选 CSV。
- 输入 H5AD 仍默认不保存。绘图用 `adata=adata` 或已保留的输入；不隐式读取磁盘上的表达归档。

| 报告 | 结构 |
|---|---|
| `analysis.report.html` | 分析概览 → 通讯概览 → 阳性事件列表 → 数据与方法 |
| `analysis.selected.report.html` | 所选事件概览 → 所选事件列表 → 事件解释与表达证据 → 筛选与方法 |

通用报告列出全量数量及阳性状态，热图、网络和列表使用全部阳性事件。
所选报告的图形与列表使用全部 selection 事件，不额外套用阳性门槛；点图只在该报告出现。

## 合并与补充

1. 每份报告只有一个事件列表；解释入口在所选列表中，不再重复生成解释索引。
2. 发送端的 P/C/E 与外排调节归入同一说明组，接收端单列；汇总评分直接显示，删除重复汇总表。
3. sample_aware 的通讯评分面板展示全部样本，包含 NA、零分、QC 和中位数；pooled 不再生成单值样本面板。
4. 表达证据复用公开小提琴图接口，相同代谢物/受体上下文合并相关细胞类型，只为解释范围生成一份并提供事件链接。
5. 发送端色标固定 0–1；全零接收端色标使用 0–1，避免出现对称的微小负值。只调整展示。
6. 全局覆盖度、输入信息与完整参数仅在通用报告出现；所选报告保留必要筛选和统计说明。
7. 所有图展开后完整显示，不使用图片内部滚动条；事件解释和表达证据默认折叠。

默认 `detail_n=10`，点图 `plot_top_n=20` 个代谢物—受体组合；不截断事件列表或 CSV。
发送/接收组成图保留前 10 个样本单元上限，明细表预览最多 100 行，报告明确记录。
小提琴图是单细胞表达证据，不是实测代谢物浓度或通量；sample_aware 图按细胞类型合并所提供输入中的细胞。
