## 2. 四层通讯关系图

- 新增公开绘图入口 `plot_communication_paths()`；支持 EventSelection、结果对象或事件表，独立绘图返回 figure/axes、节点、完整路径数据及展示范围，支持调用者导出 PNG/PDF/SVG。报告使用相同的节点与路径数据生成离线交互 SVG。
- 四列固定为发送细胞、代谢物、受体/传感器、接收细胞。身份使用完整事件键；代谢物用 HMDB 编号区分，名称仅供展示。相同细胞类型在发送、接收两列是不同角色节点。
- 每条完整路径对应一个实际所选事件，保留稳定事件编号。节点可以共享，路径记录不合并为可任意重组的相邻边，避免产生不存在的 sender—receiver 组合。
- 原方案为等宽路径、发送细胞着色；2026-09-30 按用户给定参考改为圆点及直线，节点面积表示当前页事件数、颜色区分角色，线宽表示通讯评分、线色表示所选统计量的 −log10。图注说明不是实测通量，分类型 BH 值应在同类型内解读；原评分和统计值不变。
- 悬停或键盘聚焦路径时展示完整四项身份、原评分、报告采用的统计值及达标状态；点击路径锁定高亮，点击节点高亮相关实际路径。重叠路径可以通过事件选择控件明确定位。
- 可跳转所选事件列表的对应记录；已有三级页面则提供链接，未生成时沿用现有追加代码，不自动创建三级报告。
- 路径只受 selection 与明确的展示范围限制，不追加显著性或 QC 筛选。评分或统计量缺失的已生成事件仍可展示关系，数值标为 NA，不填零。

## 3. 事件较多时的处理

- 沿用现有 `plot_top_n=20` 控制用于通讯关系图、点图和表达图的代谢物—受体组合范围；`None` 表示不限组合。报告组织层共用组合展示清单，沿用点图现有排序口径，并注明所用统计列。缺失评分的关系可保留，但不强行绘制评分气泡。
- 四层图每页默认 50 条完整事件，可搜索/按组合筛选与翻页。分页仅切换图形视图，在当前组合展示范围内的事件均可访问；节点和计数明确对应当前视图。
- 报告显示完整 selection 数量、纳入图形范围的组合/事件数量及当前页数量。超出组合展示上限的事件仍完整保留在列表和所选 CSV，报告提供调整上限的说明。
- 组合排序沿用有效评分事件的最低统计值、最高评分顺序；没有有效评分的组合置于其后。路径图可保留这些组合或同组合中评分缺失的关系，点图只绘制评分有效的事件。
- 页面内切换不重新计算评分、置换或 BH 校正；离线可用，无外部网络依赖。静态导出明确标注本图范围；图形不使用内部滚动条裁切，节点过多通过分页和对象选择处理。
- `plot_top_n` 对样本评分热图的现有“事件列数”含义保留并在说明中区分。图形展示上限不改变 CSV 或 selection。

## 4. 两类小提琴图

复用 `plot_metabolite_secretion_violin()` 和 `plot_receptor_expression_violin()`，不另写一套评分或表达计算。

| 图形 | 合并单位与细胞范围 | 准确解释 |
|---|---|---|
| 发送端生产相关表达 | 每个展示范围内的代谢物一张；合并这些所选事件涉及的发送细胞类型 | 形状为单细胞生产反应相关表达分布，颜色为已计算的细胞类型代谢物可用性评分 |
| 接收端受体表达 | 每个展示范围内的代谢物—受体组合一张；合并对应所选事件涉及的接收细胞类型 | 形状为单细胞受体表达分布，颜色为平均表达 |

- 按上述对象去重，不按完整细胞对事件重复绘图。对象选择控件切换图形；发送端对象可被多个组合复用。
- 上一版 HMDB0000961—CYSLTR1 案例只增加一张发送端图和一张接收端图，各图包含 selection 涉及的相应细胞类型。
- 使用显式 `adata`，否则使用计算时已保留的内存输入；不自动打开磁盘 H5AD。没有输入时显示一次简短说明，其余报告正常生成。
- 图片明确记录所用输入、表达层和细胞范围。sample_aware 的现有小提琴函数按细胞类型汇集所提供的细胞，须说明它不是逐样本评分分布；样本表现仍由样本热图展示。
- 两端图属于表达证据；发送端标题不称“实测分泌量”。全零或常数沿用水平线表示；图形不可用时说明原因，记录与 selection 不被删除。
- 现有三级报告继续展示具体事件的表达证据。二级侧重同一代谢物/受体在多类细胞中的比较。

## 5. 调用、追加与文件

现有调用方式即可启用上述默认行为，不增加必填参数：

```python
focus = result.select_events(hmdb_ids=["HMDB0000961"], sensor_genes=["CYSLTR1"])
result.save("analysis", selection=focus, adata=adata)

# 先保存一般结果，再追加二级报告：
result.add_selection(focus, adata=adata)

# 独立二级报告：
focus.to_html("selected.html", adata=adata)
```

- 接通 save、独立 to_html 和 add_selection 到二级表达绘图的 adata 传递链。新参数仅限独立绘图所需的可选展示配置，报告沿用现有接口。
- 追加三级时复用二级已有的表达图，只更新必要的导航/链接，避免因为此次未传 adata 而丢失已生成图形。
- 替换 selection 时按新事件范围重建图形；没有可用表达输入时明确说明，不能复用范围不符的旧图。
- 图形内嵌于 `.selected.report.html`，不默认增加 PNG、PDF、数据 CSV 或图片目录。完整 H5、阳性 CSV、所选 CSV 沿用已有含义；全量 CSV 仍仅在 `include_all_events=True` 时导出。
- 本轮不更改默认阳性统计列。分类型 BH 与全局 BH 的选择继续由用户显式设置并记录到报告；不借图形修订切换统计标准。
